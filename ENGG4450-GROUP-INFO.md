## How to work in this repository

1. This repository is your group's own copy of beets. Do all of your work here. Never push to the base repository.
2. Pick one issue from the base repository and record it in the table above. An issue is normally assigned to one group only, so confirm it with your teaching assistant first.
3. Create a development branch for your work. Do not commit straight to `main`.
4. When the implementation is finished, open a pull request from your development branch into the `main` branch **of this repository**.
5. Every member commits under their own GitHub account. Individual contributions are part of the assessment, and they are read from the commit history.
6. Write commit messages that say what changed and why, and use Issues in this repository to divide the work.
